# `@deepseek-ai/dsh-client-ui-settings-plugin-market`

[English](README.md) | 中文

向 `settings.plugins.tab` 贡献惰性 `market` 页签的 Cordis 客户端插件。搜索、分类、来源、预构建分发、已安装、排序、分页和详情状态均使用只读目录 Remote；用户筛选同步到带命名空间的 URL 参数。“预构建”只表示 npm 包或声明的 Release 包，绝不声称没有生命周期脚本。

M1 明确不提供安装操作。目录收录只表示候选项，不代表安全背书。
