## 任务依赖图

1. **Host 创建**：整合上游新会话创建及用于精确身份的显式 `exactAdopt` 请求，保留协作和部分结果错误，通过仓库构建重新生成 Remote 产物，并测试 Host 生命周期与冲突。
2. **模型所有权**：整合上游 Agent 的模型选择版本 3 投影及单一写入者，保留待用选择、冷读取和校验，并测试重放及缓存失效。该任务可能修改 Session controller，集成时处理重叠变更。
3. **客户端契约**：保留 `dedicatedCollaboration`，增加 `agentPreset` 和显式 `exactAdopt`，向消费者传播返回身份，并测试客户端行为。客户端任务以基线和约定请求字段实现，集成时核对 Host wire schema。
4. **集成**：合并 Host、模型和客户端提交，解决共享文件和生成目录的差异，运行针对性 Session、客户端、SDK 和持久化检查并编写最终报告。兼容性和升级文档须与对应变更一起完成。

Host、模型和客户端并行；集成依赖三者。任何任务均不推送、不发布、不修改 package 版本字段。锁文件变更须对照上游说明，不得无关升级依赖。
