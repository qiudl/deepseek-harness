# Agent Note：为 Windows 私有文件替换保留路径余量

状态：已实现

[English](2026-09-15-windows-private-replacement-path-budget.md) | 中文

## 问题

私有文件适配器会在完整目标路径后追加带连字符的 UUID 和 `.tmp`。MSIX 包专属目录中的 DSH 账户公钥环路径可达到 219 个字符，使临时路径恰好达到 260 个字符；因此，在较短的身份文件全部成功后，原生创建或移动操作仍会在传统 Win32 路径边界失败。

## 决策

原子替换保留 UUID 完整的 128 位随机性，但在组成同目录临时文件名之前移除四个展示用连字符。后缀从 41 个字符缩短为 37 个字符，同时不改变“排他新建、刷盘、稳定句柄校验、移动替换、失败清理”的安全流程。

## 考虑过的替代方案

**缩短持久账户公钥环文件名。** 不采用，因为这会改变既有存储契约，也无法保护其他接近相同路径边界的替换调用方。

**对打包应用禁用原子替换。** 不采用，因为崩溃可能留下只写入一部分的权限文件。

## 影响

现场 MSIX 路径将保持在传统边界以内，同时维持现有安全与持久化协议。本身过长的路径仍会在原生操作中安全失败。
